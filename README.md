# Student Performance Analysis

This project analyzes student performance data using Python, Pandas, Matplotlib, and scikit-learn.

The analysis explores relationships between academic variables and uses linear regression to predict math scores.

## Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Key Findings
- Students who completed test preparation courses scored higher on average in math.
- Reading and writing scores showed strong positive correlations with math performance.
- A linear regression model predicted math scores with reasonable accuracy.

## Skills Demonstrated
- Exploratory Data Analysis (EDA)
- Data Visualization
- Correlation Analysis
- Predictive Modeling
- Linear Regression
